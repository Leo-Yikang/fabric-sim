viz 模块

🎨 viz — 3D 可视化数据采集

定时采样链路利用率与队列深度，导出 JSON 供 Python Plotly 渲染交互式拓扑动画

模块文件

src/viz/ ├── mod.rs # TopoKind + build_viz_data() ├── data.rs # VizData / VizNode / VizLink / VizFrame ├── position.rs # 3D 坐标计算（Dumbell / LeafSpine） └── sampler.rs # TimeSeriesSampler 定时采样器

使用流程

// 1. 启用采样 let runner = SimRunner::new(topo, name, make_proto)? .with_sampling(100_000); // 每 100us 采样一次 // 2. 运行仿真 runner.run(max_time); // 3. 构造 VizData 并导出 JSON let summary = runner.summarize(); let viz = viz::build_viz_data(&runner.topo, summary, runner.sampler.frames, &TopoKind::LeafSpine{...}); std::fs::write("viz_data.json", serde_json::to_string_pretty(&viz)?)?; // 4. Python 渲染 python3 scripts/visualize_3d.py output/viz_data.json

TimeSeriesSampler 与数据结构

采样器实现

pub struct TimeSeriesSampler { interval_ns: u64, next_sample_ns: u64, prev_bytes: Vec<u64>, // 上一次的 link_bytes_sent pub frames: Vec<VizFrame>, } pub fn maybe_sample(&mut self, now: u64, bytes: &[u64], topo: &Topology) { if now < self.next_sample_ns { return; } // 利用率 = delta_bytes / (bw * interval) ... self.frames.push(frame); self.next_sample_ns += self.interval_ns; }

VizFrame 结构

pub struct VizFrame { pub time_ns: u64, pub links: Vec<LinkSnapshot>, } pub struct LinkSnapshot { pub utilization: f64, // [0, 1] pub queue_depth_bytes: u32, // 交换机端口队列深度 }

利用率基于累积字节差值计算：delta / (bandwidth_bps × interval_ns / 1e9 / 8)。

采样间隔建议设为 50–200μs。过短会增加内存消耗和 JSON 体积；过长会丢失 transient 拥塞细节。

3D 坐标计算

position.rs 根据 TopoKind 为每个节点分配 3D 坐标，使 Plotly 渲染时拓扑结构清晰可辨。

pub enum TopoKind { Dumbell { hosts_per_side: u32 }, LeafSpine { n_leaf: u32, n_spine: u32, hosts_per_leaf: u32 }, } // LeafSpine 坐标策略 // - hosts：分布在 leaf 下方，Z 轴分层 // - leaves：中间层，X 轴均匀分布 // - spines：顶层，X 轴覆盖 leaves 范围
目前支持 Dumbell 和 LeafSpine 两种拓扑的坐标计算。Fat-Tree 的 3D 坐标扩展较为直接：edge/agg/core 分别对应三层 Z 平面。
