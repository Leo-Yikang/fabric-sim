FlowDesc：流量的最小描述

pub struct FlowDesc { pub flow_id: FlowId, pub src: EntityId, pub dst: EntityId, pub bytes: u64, pub start_time_ns: u64, }

所有流量生成器最终都输出 Vec<FlowDesc>，由 SimRunner::inject_flows() 转换为 FlowStart 事件序列。

Synthetic：三维组合流量生成器

通过 PairPattern × FlowSizeDist × ArrivalProcess 的组合，覆盖绝大多数学术评估场景。

PairPattern（通信对）

  • AllToAll：所有节点两两之间各发一条流
  • Permutation：随机排列，无不动点，无热点
  • RandomPairs(n)：随机生成 n 条源目的对
  • Custom：完全自定义列表

ArrivalProcess（到达过程）

  • Simultaneous(t)：所有流同时开始
  • FixedInterval：固定间隔到达
  • Poisson：指数分布间隔，模拟突发

FlowSizeDist（流大小）

pub enum FlowSizeDist { Fixed(u64), Uniform { min: u64, max: u64 }, Pareto { min: u64, shape: f64 }, // 重尾分布 Bimodal { small: u64, large: u64, large_ratio: f64 }, }

Pareto 逆变换采样：X = x_min / U^(1/alpha)，数据中心流量典型特征（大量 mice + 少量 elephant）。

所有随机数使用 rand_pcg::Pcg64 + 显式 seed，保证跨平台、跨运行的结果可复现。

测试与使用示例

典型用法

let flows = Synthetic { nodes: (0..16).collect(), pair_pattern: PairPattern::AllToAll, flow_size: FlowSizeDist::Pareto { min: 4096, shape: 1.5 }, arrival: ArrivalProcess::Poisson { start: 1000, mean_interval_ns: 50_000, }, seed: 42, }.generate(); runner.inject_flows(flows); runner.run(1_000_000_000);

单元测试覆盖

  • Fixed + Simultaneous：正确数量和大小
  • Pareto 重尾：最大值远超 min
  • Bimodal 比例：large_ratio 统计验证
  • Poisson 单调性：时间非递减
  • Permutation 无不动点 + 双射
  • RandomPairs 精确数量 + src≠dst
Synthetic 是矩阵测试（matrix_workloads.rs）的核心工具，系统覆盖拓扑 × 协议 × 分布 × 到达 × 模式的组合。
