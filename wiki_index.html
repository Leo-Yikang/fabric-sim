核心引擎与基础设施
🎯

core — DES 引擎

离散事件仿真核心：Event、EventKind、EventQueue（4-ary heap）、Simulator。与网络概念完全解耦，可独立复用。

4-ary heap FIFO 稳定性 整数运算
🌐

network — 网络物理层

Packet 结构、单向链路模型、多端口交换机（PFC + ECN + 多优先级队列）、丢包归因统计、主机硬件延迟模型。

PFC ECN DropCounters
🚀

sim_runner — 端到端主循环

集中式事件分发 orchestrator：PacketSlab 分配器、主机/交换机事件处理、TrainingJob 注入、仿真摘要汇总。

Slab 事件分发 Pacing
协议、拓扑与流量
🔌

nic — 可插拔协议栈

Protocol trait 抽象、STrack（Spraying + SACK + 多路径 CC）、SimpleTcp、DCQCN、HPCC、Swift、RDMA 核心抽象。

STrack SACK RDMA
🗺️

topology — 拓扑生成器

Leaf-Spine、Fat-Tree（k-ary）、Dumbell、Multi-Rail。自动计算 ECMP 路由表与 Entity ID 分配规则。

ECMP Fat-Tree Leaf-Spine
📡

traffic — 流量生成器

Incast、AllReduce、AllToAll、Synthetic（流大小分布 × 到达过程 × 通信对模式）、Mix 混合流量。

Synthetic Pareto Poisson
观测、可视化与训练 Workload
📊

monitor — 指标采集

FCT 统计（P50/P95/P99）、丢包明细（分原因/逐流/逐端口）、事件直方图、运行剖面、CSV/JSON 导出。

FCT DropCounters CSV/JSON
🎨

viz — 3D 可视化

时序采样器、VizData 构造、3D 坐标计算。配合 Python Plotly 渲染交互式拓扑动画与热力图。

Plotly TimeSeries JSON 导出
🧠

training — 训练 Workload

CollectiveOp（AllReduce/AllGather/AllToAll）、Ring/Tree/RS+AG 算法、TrainingJob 静态展开为 FlowDesc。

AllReduce Ring ChunkConfig
